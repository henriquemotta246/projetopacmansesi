COMO ABRIR E RODAR O JOGO
Baixar o Código do GitHub:

Acesse a sua conta do GitHub no navegador.

Entre no repositório onde o projeto do jogo está salvo.

Faça o download dos arquivos em formato .zip e descompacte a pasta, ou clone o repositório diretamente na sua máquina.

Abrir no VS Code:

Abra o Visual Studio Code (VS Code).

Acesse a opção Arquivo > Abrir Pasta (ou File > Open Folder) e selecione a pasta do projeto.

Certifique-se de que os três arquivos principais (index.html, style.css e script.js) estão visíveis no painel lateral do VS Code.

Executar no Navegador:

Clique com o botão direito sobre o arquivo index.html e selecione Open with Live Server (caso tenha a extensão instalada) ou abra a pasta no seu computador e dê um duplo clique no arquivo index.html.

O jogo abrirá no seu navegador padrão e estará pronto para jogar!

COMO JOGAR
1. Início e Personalização
Digite o seu Nome de Jogador na tela inicial para registrar suas pontuações no ranking.

Acesse a aba de Fantasias para escolher o visual personalizado do seu Pac-Man.

Clique no botão Start Game para dar início à partida.

2. Comandos do Jogo
Você pode jogar utilizando tanto o teclado quanto um controle de videogame (USB ou Bluetooth):

Teclado: Use as Setas Direcionais ou as teclas W, A, S, D para movimentar o personagem.

Controle (Gamepad): Utilize o D-Pad (botões direcionais) ou a Alavanca Analógica Esquerda.

3. Objetivos da Partida
Comer as pastilhas: Percorra todo o labirinto e coma todas as pastilhas amarelas para limpar o mapa e avançar de fase.

Fugir dos fantasmas: Evite o contato com os 4 fantasmas. Fique atento às cores e comportamentos deles, pois cada um possui poderes específicos (perseguidor, estrategista, veloz, atirador ou suporte).

Usar os túneis de teletransporte: Utilize as passagens nas laterais esquerda e direita do mapa para se teletransportar instantaneamente para o outro lado e escapar dos fantasmas.

Bater o Recorde: Acumule a maior pontuação possível para registrar seu nome no ranking salvo no jogo!
